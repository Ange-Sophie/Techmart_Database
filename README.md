# TechMart Database

## Project Overview
This project is about creating and managing a relational database for an e-commerce platform called TechMart. I used MySQL with XAMPP to create the tables, add constraints, and manage the data.

## Database Tables
The database contains four tables: Customers, Products, Orders, and OrderItems. These tables are connected using primary keys and foreign keys.

## Database Operations
I used DDL commands to create and modify the database tables. I also used DML commands to insert, update, and delete records. I tested different constraints to check that the database works correctly.

## Entity Relationship Diagram
I created the ERD using phpMyAdmin Designer. It shows how the four tables are connected.

- XAMPP
